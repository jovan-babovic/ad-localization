# Example ads

The ads in `examples/input/` are demo ads for PropFusion's Field Mode. PropFusion is Jovan Babovic's own company.
They're the ads from the [write-up](https://refrain.team/blog/ad-localization-workflow): 6 text ads (2 Google,
2 Meta, 2 LinkedIn), 2 image ads and a 31.5-second cut of a longer Field Mode video. None of them has run as a
campaign. They're here so you can watch the job run end to end with `/localize example`. Your images will use your
Mac's fonts, so they won't match the write-up exactly.

The ads belong to PropFusion and are **not** covered by this repository's MIT license. You may keep them in clones
and forks of this repository to try the job. Don't use them in your own ads or publish them anywhere else.

Meta's ad guide publishes limits only for primary text and headlines, so the kit shows "Limit not known" for the
Meta description lines.

The example settings in `examples/config/` are covered by the MIT license, like the code.
