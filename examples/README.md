# Example ads

The ads in `examples/input/` (the Field Mode video, both image ads and the ad copy) are demo ads made for
PropFusion's Field Mode. They belong to PropFusion and are included only so you can watch the job run end to end
(`/localize example`). They are **not** covered by this repository's MIT license: don't reuse, publish or
redistribute them outside of trying this job.

The example settings in `examples/config/` are covered by the MIT license, like the code.
